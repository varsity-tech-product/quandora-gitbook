# 版本、运行与账户

用名称查找研究，用准确选择的对象和运行执行操作。两个条目可以同名，却仍是不同对象。

| 对象 | 代表什么 | 如何变化 |
| --- | --- | --- |
| 因子结果 | 已评估因子及其记录证据 | 新实验产生新证据 |
| 策略 | 不可变的因子组成与配置 | 编辑会在同一文件夹下创建新策略 |
| 策略回测 | 对策略的一次历史评估 | 重新回测产生另一运行 |
| 组合 | 不可变的成员策略与初始权重 | 修改成员或权重会在同一文件夹下创建新组合 |
| 组合回测 | 使用已确定成员运行和区间的一次评估 | 重新回测产生另一结果 |
| 账户 | 模拟或实盘活动的容器 | 账户管理不重写研究 |
| 交易运行 | 绑定来源的一段前向观察或执行 | 启动另一运行产生独立历史 |
| 发布或分享 | 对自有组合研究的授权访问 | 分享改变访问权限，不改变研究定义 |

## 修订、重新运行与归档

修订改变定义；重新运行保留定义、产生新的评估。归档按产品规则改变可用性或组织状态，不表示停止执行，也不抹除历史账本。文件夹用于组织研究，本身不是策略或组合定义。

针对单个策略的操作，不应理解为归档其文件夹中的全部策略。同样，选中新的组合版本，不会把正在运行的账户迁移过去。

## 账户与运行

一个账户可能具有运行历史。读取业绩或请求暂停、恢复、停止前，应先选择目标运行。暂停和停止具有不同生命周期语义，详见[模拟账户与运行](../guides/paper-trading-tutorial.md)。

自动模拟观察可以关联已有的不可变组合。应检查关联的实际来源，不能假定它属于页面展示的最新回测。

## 让比较可追溯

每次比较应记录定义、运行、区间和证据截止时间。修订后开始独立的验证阶段，不要把不同调参版本中的最佳时期拼接成一条前向业绩记录。

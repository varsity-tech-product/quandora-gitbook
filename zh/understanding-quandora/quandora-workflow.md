# 工作流总览

网页和 Agent 插件围绕同一组研究对象提供七个工作流。构建产生证据，分析解释已有证据。你可以暂停、回到前一阶段，也可以直接使用已有对象。

| 工作流 | 输入 | 产出 | 证据类型 |
| --- | --- | --- | --- |
| [因子挖掘](../getting-started/quickstart.md) | 假设、任务或因子源码 | 已验证的因子与评估运行 | 回测 |
| [因子分析](../guides/factor-analysis.md) | 准确的因子结果 | 样本内诊断与实验建议 | 回测 |
| [策略构建](../guides/strategy-tutorial.md) | 1–20 个可用因子 | 不可变策略定义及回测 | 回测 |
| [策略分析](../guides/strategy-analysis.md) | 准确的策略回测 | 对组合交易规则的诊断 | 回测 |
| [组合构建](../guides/portfolio-building.md) | 1–5 个不同策略 | 不可变组合、权重与回测；按要求分享 | 回测 |
| [组合分析](../guides/portfolio-analysis.md) | 准确的组合回测 | 相对指定基准的增量价值证据 | 回测 |
| [组合交易分析](../guides/portfolio-trading-analysis.md) | 模拟或实盘账户及运行 | 基于账本的前向诊断；按要求管理模拟盘 | 前向验证 |

## 网页与 Agent 入口

**Research** 包含因子和策略；**Portfolio Center** 包含 Markets、Mine 和 Favorite；**Trading** 包含模拟与实盘账户。部分交易控件仍以 **Paper** 表示模拟盘。

Agent 根据自然语言请求选择对应 Skill。仅请求分析时保持只读；请求“构建并回测”时，授权覆盖这两个步骤，不会因为切换 Skill 失效。只有缺少重要选择或必要授权时才需要追问。

## 分清对象与运行

策略定义因子的组合方式。组合定义成员策略及其初始资金权重。修改策略或组合会在同一文件夹下创建新定义；对不变定义重新回测会创建新回测运行。账户观察则属于某次前向运行。

名称用于查找，但不同对象可以同名。比较、修订和模拟盘都必须对应准确的定义与运行。详见[版本、运行与账户](versions-and-runs.md)。

## 进入前向验证

完成组合回测后，可能已有自动关联的模拟观察。创建另一账户或运行之前，先检查该关联及其来源。单策略通过单成员组合走同样的路径。另建命名模拟账户是单独的选择。

分析可以建议实验，但不会自动修改组合或停止账户。实盘设置和执行操作由符合条件的用户在网页完成；Agent 只读取已有实盘证据。参见[模拟账户与运行](../guides/paper-trading-tutorial.md)及[实盘访问边界](deployment-and-live-trading.md)。

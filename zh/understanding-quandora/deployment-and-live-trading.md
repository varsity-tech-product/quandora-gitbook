# 实盘访问边界

实盘使用真实交易所活动和资金，仍需邀请，并受账户显示的资格限制。研究结果、模拟账户或已安装插件，不会授予实盘执行权限。

## 网页与 Agent 的职责

| 任务 | 所在入口 |
| --- | --- |
| 查看已授权自有实盘账户、运行、仓位、订单、成交和业绩 | 网页或只读的组合交易分析 |
| 连接交易所账户或提供凭据 | 产品支持的网页流程，不在 Agent 提示词中提交 |
| 准备或启动实盘、停止实盘运行、平掉实盘仓位 | 已授权的网页控件 |
| 管理模拟账户和运行生命周期 | 网页或组合交易分析，限于请求范围 |

插件不执行实盘账户创建、凭据提交、实盘启停或平仓。启动模拟盘的请求，不能复用为任何实盘操作的授权。

## 网页操作

打开 **Trading → Live** 检查你可访问的账户。使用执行控件前，核对账户、选定组合、运行及界面详情。访问或操作不可用时，遵循产品显示的资格信息；Agent 无法绕过限制。

本指南不承诺每个账户均可访问、某一具体交易场所或统一风险限额。以已授权账户实际显示的控件与要求为准。

基于证据的检查见[分析模拟盘与实盘](../guides/portfolio-trading-analysis.md)，功能范围见[功能可用性](../trust/product-availability.md)。

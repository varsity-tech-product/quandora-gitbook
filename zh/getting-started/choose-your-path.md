# 选择你的路径

从已有内容出发。使用已有策略或探索社区组合时，不必先挖掘新因子。

| 你已有的内容 | 下一步 | 完成后的产出 |
| --- | --- | --- |
| 市场假设或因子代码 | [因子挖掘](quickstart.md) | 一份已评估的因子结果 |
| 因子结果 | [因子分析](../guides/factor-analysis.md) | 诊断和下一项受控实验 |
| 可用于策略的因子 | [策略构建](../guides/strategy-tutorial.md) | 策略定义及其回测 |
| 已完成的策略回测 | [策略分析](../guides/strategy-analysis.md) | 完整交易规则的评估证据 |
| 一至五个已评估策略 | [组合构建](../guides/portfolio-building.md) | 带权重的组合及其回测 |
| 组合结果 | [组合分析](../guides/portfolio-analysis.md) | 与成员策略及指定基准的比较 |
| 已运行的模拟或实盘账户 | [组合交易分析](../guides/portfolio-trading-analysis.md) | 基于该次运行实际账本的诊断 |

## 我更习惯网页

在 **Research → Factors / Strategies** 浏览研究，在 **Portfolios** 打开组合中心，在 **Trading** 打开账户。各教程会指出对应控件。因子的编写与提交使用 Agent 工作流；Factors 页面用于浏览、检查结果。

## 我更习惯 Agent

先完成[安装指南](installation-guide.md)。说明你的目标和要操作的对象即可，无需记住命令或工具名称。存在多个同名对象时，提供结果链接，或按提示选择准确版本和运行。

## 我想探索社区组合

打开 **Portfolio Center → Markets → Community**，查看组合并收藏。启动自己账户中的授权模拟盘之前，先阅读[社区与分享](../guides/community-and-sharing.md)。浏览或收藏组合不会转移其所有权。

## 我刚接触量化研究

先阅读[Quandora 入门](quandora-101-for-non-quants.md)，再选择上述路径。遇到术语可以查阅[术语表](../understanding-quandora/glossary.md)，也可以让 Agent 用当前结果解释。

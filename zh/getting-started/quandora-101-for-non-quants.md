# Quandora 入门

Quandora 帮助你测试交易想法、理解证据，并观察它在新条件下的表现。你可以使用网页、AI Agent，或结合两者。

## 先理解四类对象

| 对象 | 简单解释 | 示例 |
| --- | --- | --- |
| 因子 | 为市场生成分数的规则 | 用与流动性有关的信号对市场排名 |
| 策略 | 由因子分数组成的交易规则 | 组合两个可用因子，选取头部/尾部市场 |
| 组合 | 一个或多个策略及其初始资金分配 | 将 70% 分给核心策略，30% 分给互补策略 |
| 账户与运行 | 对组合进行前向观察的载体 | 启动模拟盘，检查仓位与成交 |

示例用于说明对象，不代表投资建议或最优参数。名称只是标签，不同对象可以同名；保存的定义和具体运行决定了究竟测试什么。

## 三类不同问题

**想法是否具有有用的历史证据？** 挖掘并分析因子。

**完整交易规则或策略组合在测试假设下是否有效？** 构建并分析策略，适当时再构建和分析组合。

**启动后实际发生了什么？** 通过组合交易分析，检查模拟盘或已授权实盘证据。

这些问题使用不同证据。因子等级不能证明组合有用，回测不能证明未来表现，模拟执行与真实实盘执行也属于不同观察。

## Agent 提供什么帮助

Agent 可以将假设转为因子代码，执行已授权研究，解释保存的结果，并按要求完成支持的账户操作。它应明确证据对象，保留缺失信息，并区分自身解释与产品实际记录。

你也可以直接在网页浏览结果、构建策略或组合，无需编写代码。教程会在产品支持的地方提供两种路径。先阅读[选择你的路径](choose-your-path.md)或[工作流总览](../understanding-quandora/quandora-workflow.md)。

# 产品功能可用性

Quandora 将公众研究工具与受控的真实资金执行分开。

| 功能 | 可用性 |
| --- | --- |
| 因子挖掘与因子回测 | 对公众用户开放 |
| 因子卡与研究结果文件 | 对公众用户开放 |
| 策略组合与策略回测 | 对公众用户开放 |
| 策略模拟盘与监控 | 对公众用户开放 |
| 使用真实资金的实盘交易 | 仅限内部邀请，不对一般公众开放 |

## 公众研究工作流

公众用户可以测试因子想法、评估证据、把可用因子组合成策略、回测策略，并用模拟订单观察策略运行。

这些结果描述历史或模拟表现，不构成未来收益承诺或直接的买卖指令。

## 邀请制实盘交易

实盘交易只能通过内部邀请使用，并需要独立审核和授权。拥有公众账户、因子卡、策略回测或模拟盘结果，并不代表获得实盘权限。

获得邀请后，实盘能力只会在分配给账户的权限和限制内执行用户批准的策略，不授权 Quandora 自主做出交易判断。

# 功能可用性

本指南介绍网页和 Quandora 插件中的七个工作流。请通过已安装插件的 Skill 列表和账户可见控件确认访问能力。如果旧插件仍显示五个 Skill，请按[安装指南](../getting-started/installation-guide.md)更新。

| 功能 | 范围与访问边界 |
| --- | --- |
| 因子挖掘 | 历史研究；Agent 编写和提交，网页浏览结果 |
| 因子分析 | 只读检查自有或可访问有效官方结果的已保存样本内证据 |
| 策略构建 | 使用 1–20 个可用因子，进行历史策略回测 |
| 策略分析 | 只读检查自有或已授权社区研究 |
| 组合构建 | 1–5 个不同策略、初始权重、组合回测、社区发现、收藏和按要求分享 |
| 组合分析 | 只读比较实际组合及其来源的历史证据 |
| 组合交易分析 | 按要求管理模拟账户/运行，分析模拟盘及已授权自有实盘证据 |
| 真实实盘执行 | 需邀请且受账户资格限制；设置与执行控件在网页，不在插件 |

## 访问权限针对对象与操作

能够看到研究，不代表拥有、可复用或可交易。共享组合可能展示研究，但当前交易资格不可用。账户限制、分享到期、来源准备状态及当前权限，都由产品在对应操作时检查。

网页与 Agent 控件不必完全相同。网页展示的假设，不一定是 Agent 可编辑输入。不要从旧命令示例推断当前支持参数或权限。

## 证据边界

前六个工作流使用历史回测，组合交易分析使用启动后的观察。历史样本外仍属于回测。模拟盘使用建模执行，实盘使用真实资金。良好的回测或短期成功前向运行，均不保证未来表现。

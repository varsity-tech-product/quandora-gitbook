# 产品功能可用性

Quandora 将公开研究与模拟和真实资金执行分开。

| 功能 | 可用性 |
| --- | --- |
| 因子挖掘 | 对公众用户开放 |
| 因子分析 | 对公众用户开放；只读 IS 证据 |
| 策略构建与回测 | 对公众用户开放；截面策略 |
| 策略分析 | 对公众用户开放；只读 |
| 模拟盘 | 对公众用户开放；模拟订单 |
| 使用真实资金的实盘交易 | 不属于当前公开产品 |

## 公开研究工作流

公众用户可以测试因子想法、分析明确的因子结果、把符合条件的因子组合成截面策略、分析明确的策略结果，并使用模拟订单运行符合条件的来源。

这些研究结果描述历史或模拟表现，不承诺未来收益，也不构成直接的买卖指令。

## 实盘交易边界

当前公开产品契约不提供真实资金执行。公众账户、因子卡、策略结果、模拟盘运行、插件命令或 Result Bundle 都不会授予或暗示实盘交易权限。本页也不声明任何 Broker Permission Model 或实盘控制系统已经公开可用。

# Quandora 简介

<figure><img src=".gitbook/assets/orange%20gradient%20logo.png" alt="Quandora"><figcaption></figcaption></figure>

## Quandora 是什么

Quandora 是面向 AI 原生量化交易工作流的金融 Agent 基础设施。

我们为金融 Agent 提供因子挖掘、因子评估、策略构建、策略评估、模拟盘和监控能力。你的 Agent 最终会给出结构化报告，说明测试了什么、哪些条件通过或失败，以及下一步应该改进什么。

[创建或登录 Quandora 账户](https://app.quandora.ai/auth/signin)，然后根据你的经验和目标[选择使用路径](getting-started/choose-your-path.md)。

## 我们的观点

当交易越来越依赖 Agent，严肃的 Agent 也会越来越接近量化研究。它需要数据、验证、反馈循环、风险控制和可复查的证据，才能形成可靠判断。

金融市场不缺另一个聊天机器人，缺的是：

* 信号验证；
* 过拟合检查；
* 微观结构与流动性分析；
* 真实的成本与换手评估；
* 回测与样本外检查；
* 可复查的因子研究记录；
* 报告与审计轨迹；
* 具备安全边界的工作流。

Quandora 提供一套研究证据系统，帮助你判断一个想法是否通过验证、是否在样本外失效、是否已经衰减或重复了以前的尝试，并理解交易成本对结果的影响。

{% hint style="info" %}
因子挖掘、策略回测和策略模拟盘对公众用户开放。实盘交易采用内部邀请制，暂未向一般公众开放。所有结果仅供研究与评估，不构成收益承诺或跟单建议。目前首先支持加密市场。
{% endhint %}

# 社区与分享

通过组合构建流程发现、收藏或分享组合。阅读共享结果不会转移所有权，也不会让每个成员都自动成为自己的研究素材。

## 网页操作

打开 **Portfolio Center**：

| 视图 | 内容 |
| --- | --- |
| Markets → Community | 当前对你可见的组合发布内容 |
| Markets → Official | 官方集合，可能显示 **Coming soon** |
| Mine | 自己的组合 |
| Favorite | 已收藏的发布内容 |

打开卡片，检查作者、简介、组成和可用研究。点击星标添加或移除收藏。研究准备中应保持待就绪状态；空白图表不代表零收益。

自己的组合可通过详情页提供的分享控件操作，提交前核对受众、有效截止日期和当前分享状态。网页提供的控件可能少于下述 Agent 流程。

## 向 Agent 提问

只发现，不修改：

```text
使用 Quandora Portfolio Building 查找与我研究目标相关的社区组合。展示作者、可用研究及当前模拟盘资格，不要收藏、复制、分享或启动任何内容。
```

收藏选定发布内容时，请明确要求 Agent 收藏。分享时应明确自己拥有的准确组合、受众和到期时间，例如：

```text
把这个准确组合分享给刚才选定的 Quandora 用户，有效期到我指定的日期。保持组合定义和回测不变。
```

缺少收件人或日期时，Agent 必须先明确。公开发布与定向分享的受众不同；授权分享给一个人，不代表授权公开发布。

## 分享承诺

分享必须指定有效截止日期，按 UTC 包含当日，没有永久或默认到期时间。存在有效授权时，公开和定向渠道不能混用。有效授权不能撤销、缩短、移除或切换渠道；可以延长至更晚日期，过期授权不能通过延长恢复。

编辑分享简介不会修改组合定义或重新运行研究。将自己的组合下架，也不能撤销已生效的分享承诺。

到期后，保留的共享研究可能仍可阅读。当前发现范围和交易资格以该发布或分享返回的权限为准，不能仅凭结果可见就推断允许交易。

## 在授权上下文中使用研究

从发布内容进入的策略和因子分析，应保持其授权上下文。可查看结果不代表可以获取私有源码，也不能把仅限所有者的对象复制进 Mine 来绕过权限。

明确请求模拟盘时，使用符合条件的发布或分享，在**自己的账户**中运行。组合交易分析会在启动或恢复时检查当前权限。详见[模拟账户与运行](paper-trading-tutorial.md)。

## 完成标准

发现结果明确发布内容和可用证据；收藏请求报告已保存状态；分享请求报告准确受众与到期时间。这些操作均不隐含创建另一个组合或回测。

# 策略使用教程

策略组合与策略回测对公众用户开放。

完整的界面操作教程正在准备中，后续将包括：

* 查找可以加入策略的因子；
* 验证或导入尚未进入可选列表的自有因子；
* 选择并组合可用因子；
* 提交前检查策略参数；
* 判断应该新建、修订、分叉还是重新运行；
* 对一个明确的策略版本运行回测；
* 阅读运行状态、表现、风险和结果文件；
* 在不丢失旧定义和证据的前提下修订策略。

## 选择正确的动作

| 你的目的 | 选择 |
| --- | --- |
| 构建一个独立策略 | **新建（Create）**：从 Version 1 开始 |
| 改进同一个策略 | **修订（Revise）**：在原策略历史中增加一个不可变版本 |
| 从已有版本探索一个独立策略 | **分叉（Fork）**：创建新的 Version 1，并保留来源关系 |
| 再次测试完全相同的策略 | **重新运行（Rerun）**：创建新运行，不创建新版本 |

因子选择、权重、排序方式、策略类型和再平衡规则决定“这个策略是什么”。测试日期、初始资金和仅用于本次测试的假设属于一次运行。改变运行设置时，不应该静默创建新的策略定义。

## 运行时会发生什么

策略运行会经历多个状态，最终计算结果与可下载文件不一定同时准备完成。尚未准备好的文件应显示为等待中，待运行完成后再确认结果。

如果提交确认过程中断，不要马上重复提交。先让产品或 Agent 确认原来的尝试是否已经创建，避免产生重复实验。

有关策略组成和评估指标，请阅读[策略构建](../understanding-quandora/strategy-construction.md)。

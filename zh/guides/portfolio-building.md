# 构建组合

将**一至五个不同策略**按初始资金分配组成组合，再评估合并后的历史结果。单成员组合有效，五个是上限，不是目标。

## 开始之前

选择符合条件、已评估的策略，并明确目标，例如降低核心策略回撤或某项敞口。先选择有可信证据的核心策略，识别主要弱点，再考虑补充成员。名称不同或相关性较低，本身不足以证明收益来源独立。

用户明确指定成员和权重时，应保留这些选择。委托 Agent 选择时，应说明实际检查了哪些候选、哪些尚未验证。参见[分析策略](strategy-analysis.md)。

## 网页操作

1. 打开 **Portfolio Center → Mine → New portfolio**。
2. 在 **Select strategies** 从自己的库中选择 1–5 个已完成策略回测，点击 **Continue**。
3. 在 **Allocate capital** 输入组合名称，可选配图，检查每个成员的资金分配和对应权重。遵循表单显示的最低金额和调整步长。
4. 检查总分配金额与 **BTC** 回测基准，再提交 **Create**。
5. 打开已创建组合，跟进回测。比较业绩前，检查实际使用的成员结果和共同区间。

等初始资金是有用的基线，不等于等风险贡献，也不表示每天再平衡或权重始终不变。

## 向 Agent 提问

先请求方案：

```text
使用 Quandora Portfolio Building，以我的 Core Strategy 为核心提出组合方案。寻找一个可能降低其回撤的互补策略。解释候选范围、证据、初始权重和缺口，暂时不要创建。
```

对于已经确定并授权的构建：

```text
用刚才选定的两个准确策略，按 70% 和 30% 初始资金权重创建并回测 Core and Diversifier。保留这些权重，与核心策略比较结果，不要启动额外模拟账户。
```

自定义权重必须为正数且总和为一。Agent 使用当前组合契约，不添加任意资金、日期、手续费、杠杆或成员运行覆盖参数。服务会确定实际用于组合评估的策略回测和共同窗口，应在返回结果中核对来源。

## 理解准备状态

**Preparing sources** 表示正在准备成员研究；**Running** 表示组合评估进行中。应跟进同一次运行，这两种状态都不是重复提交的理由。失败时应说明可用的原因。

组合结果和 BTC 基准可能分别就绪。基准准备中，不代表已完成组合结果为空。

## 修订与自动观察

修改成员或权重，会在同一文件夹下创建新组合。旧研究和运行中的账户仍保持原定义。对不变组合重新回测会产生另一回测运行，不会改变组成。

回测完成后，检查自动关联的模拟观察及其来源。该关联可能来自同一不可变组合的较早回测。关联仍在准备时，不代表可以创建重复账户。另建命名模拟账户是[组合交易分析](paper-trading-tutorial.md)中的明确后续操作。

## 完成标准

可以明确定位组合、成员策略、初始权重、实际来源运行、测试区间及结果状态。使用[组合分析](portfolio-analysis.md)判断增量价值；使用[社区与分享](community-and-sharing.md)发布或分享已有组合，无需为分享重新回测。

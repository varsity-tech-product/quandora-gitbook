# 分析组合

判断策略组合是否为既定目标带来增量价值。此流程分析已有回测，不会提交新实验。

## 开始之前

明确准确的组合回测、实际成员策略运行、初始权重及评估区间。在判断结果前说明目标和基准；如果事先没有目标，应将此次评估标记为探索性分析。

可用基线包括核心策略、各实际成员，以及已有的同成员等资金组合。事后选出的最佳成员可以作为注明依据的额外参照，但不能替换原始基线。尚未运行的基线保持不可用。

## 网页操作

1. 从 **Mine**、**Favorite** 或 **Markets** 打开组合，保持其所有权或分享上下文。
2. 阅读选定回测、组成、资金分配和来源结果。
3. 检查净值、收益、回撤及其他可用指标；BTC 基准就绪后再进行对应比较。
4. 打开相关成员研究，核对共同日期和成本假设，再判断差异是否代表组合改善。

## 向 Agent 提问

```text
使用 Quandora Portfolio Analysis 分析这次回测，目标是降低核心策略回撤。比较实际成员运行，以及已有的同成员等资金基线。根据证据解释净收益/风险、集中度、分散化和执行成本，不要创建缺失对照或修改组合。
```

简明结论应属于以下一种：

| 结论 | 含义 |
| --- | --- |
| 历史证据支持改善 | 可比证据支持既定目标，并说明观察到的取舍 |
| 收益与风险取舍 | 部分维度改善，同时在其他维度付出明确代价 |
| 未证明改善 | 可比证据未显示与目标有关的收益 |
| 证据不足 | 缺少关键证据或可比性 |

## 证据能够说明什么

初始资金权重不等于风险贡献权重。策略名称、独立 Sharpe 或孤立图表无法证明相关矩阵或市场中性。相关性与联合风险指标需要对齐的底层观察和明确的计算方法。

净业绩比较需要兼容的成本口径。方向相反的仓位本身不能证明已实现净额执行节省。Sharpe 上升也不能单独证明独立 Alpha、尾部风险下降或持久的分散化效果。

判断某成员是否有帮助时，可以使用已有的移除该成员对照，并说明剩余资金如何分配、其他条件如何保持不变。如果对照不存在，应提出实验，而非静默运行所有子集。

## 完成标准

分析给出一个主要结论、决定性证据、重要缺口，以及最小有用后续实验。在同一历史样本上选取并评估，不属于样本外验证。[前向测试](paper-trading-tutorial.md)会建立另一份实际观察记录。

# 模拟账户与运行

使用组合交易分析管理模拟账户，并观察组合启动后的行为。部分网页控件仍以 **Paper** 表示模拟盘。这些运行使用模拟执行，不使用真实资金。

## 开始之前

选择符合条件的自有组合，或已获授权的社区发布/分享。单策略需要先创建并回测单成员组合。创建另一账户之前，先检查是否已有自动模拟关联。

账户与运行是不同对象。先明确你要检查已有运行、在已有账户中启动，还是另建命名账户。账户配额与初始设置由产品执行检查。

## 网页操作

1. 打开 **Trading**，选择 **Paper**。从列表打开已有账户，查看当前运行或运行历史。
2. 如需额外账户，点击 **Create Paper account**，输入名称并提交 **Create account**。仅创建账户，不等于已选定组合或开始执行。
3. 在账户的选择流程中选定符合条件的组合，检查展示设置，准备好后提交启动操作。
4. 检查返回的运行状态，按需阅读 **Current Position**、**Closed positions**、**Filled Record** 和净账户详情。
5. 仅对目标运行使用 **Pause**、**Resume** 或 **Stop**。账户管理与运行执行是不同操作。

## 向 Agent 提问

先检查，不启动：

```text
使用 Quandora Portfolio Trading Analysis 查找这个组合已关联的模拟盘。说明账户、准确运行、来源和当前状态，不要创建或启动其他账户。
```

确实需要额外账户时：

```text
创建名为 Core Observation 的模拟账户，启动我们选定的准确组合，使用已约定的初始杠杆。跟进同一操作到最终状态，报告账户与运行。初次响应延迟时不要创建替代账户。
```

缺少必要设置时，Agent 会追问。超时或响应不确定时，应恢复同一操作。**Accepted** 代表请求已接受，不代表已经运行。启动失败可能保留已创建账户，仍应报告并管理该账户。

## 生命周期与账户操作

| 操作 | 含义 |
| --- | --- |
| 重命名账户 | 修改账户名称，保留历史 |
| 归档/恢复账户 | 根据资格和配额改变可见性或可用性，不停止、重置或删除历史 |
| 启动 | 在选定账户中启动新的合格组合运行 |
| 暂停 | 请求暂停当前运行，以返回状态为准 |
| 恢复运行 | 检查当前计划和分享资格后，继续符合条件的暂停运行 |
| 停止 | 结束该次运行，已停止运行不可恢复 |

停止后再次启动会产生新运行。账户重置、历史删除和修改运行中资金不属于插件能力。归档账户不能代替停止运行。结算或其他状态转换期间，应等待同一操作的结果，避免强行创建新的启动请求。

## 完成标准

账户与准确运行已定位，最终返回状态明确，来源组合符合意图。仅请求业绩分析，不会授权暂停、停止、新版本或新账户。

接着阅读[分析模拟盘与实盘](portfolio-trading-analysis.md)。真实实盘执行控件由符合条件的账户在网页使用；模拟盘授权不包含任何实盘操作。

# 分析因子

判断因子的已记录表现是否支持其假设，以及下一项实验应澄清什么。这是只读的回测分析流程。

## 开始之前

选择自己的一次因子运行，或有权访问的有效官方因子结果。名称重复时，用结果链接或准确选择定位。因子分析读取已保存的**样本内（IS）**证据，不声称拥有未提供的样本外表现，也不依赖本地 ZIP。

## 网页操作

1. 打开 **Research → Factors**，选择相应库或文件夹。
2. 打开因子，确认要分析的具体结果。
3. 分别阅读[成功/失败、Health 和等级](../understanding-quandora/how-factors-are-judged.md)。运行完成不代表因子成功，等级本身也不决定策略可用资格。
4. 结合指标与可用图表检查预测方向、稳定性、覆盖率、换手和成本，它们反映不同方面的问题。

## 向 Agent 提问

```text
使用 Quandora Factor Analysis 分析这份结果。解释假设及已记录的样本内证据，包括可用的 Health、Rank IC、自相关、Sharpe、换手与建模成本。区分观察和推断，提出一项实验，但不要运行。
```

Agent 应说明使用了哪份准确结果、哪些证据不可用，以及如何用证据区分主要解释与替代解释。对于官方因子，不应读取或推测其私有源码。

## 完成标准

结论将因子机制与已记录证据联系起来，并说明限制。缺失的 Health 或其他必要证据保持未知。成本用于诊断，不构成额外的成功/失败门槛。

测试改进请使用[改进并重新运行](improve-and-rerun.md)。组合因子请使用[策略构建](strategy-tutorial.md)，该流程会重新检查实际可用的因子池。

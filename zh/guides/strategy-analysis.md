# 分析策略

评估完整交易规则，避免只根据单个因子等级推断策略表现。开始前，选择自己拥有或通过授权社区组合访问的一次已完成策略回测。

## 网页操作

1. 打开 **Research → Strategies** 并选择目标结果。社区研究应从共享组合的研究视图进入。
2. 检查因子、权重、方向、排名及实际测试窗口。
3. 根据保留的证据，检查业绩、回撤、敞口、换手、手续费、资金费和归因。
4. 仅比较时期与假设兼容的结果。注意范围标签：**ALL 包含 IS**，不属于纯样本外证据。

## 向 Agent 提问

```text
使用 Quandora Strategy Analysis 分析这次准确运行。根据已保存证据解释净业绩、回撤、换手和成本、敞口，以及可支持的因子贡献。指出主要弱点和一项受控后续实验，保持只读。
```

分析社区研究时，提供正在查看的组合发布内容，让 Agent 保持相应授权上下文。能够看到成员策略，不代表拥有它，也不代表可无限制访问其因子或源码。

## 完成标准

分析明确运行对象，区分观察与推断，并说明结果是否支持继续测试。缺失图表或归因证据保持不可用，不能根据独立因子的 Sharpe 或组合收益截图编造因子贡献。

下一步由你选择：通过[策略构建](strategy-tutorial.md)修订，评估其在[组合](portfolio-building.md)中的作用，或保留结果而不继续操作。分析建议不会修改已有策略或启动模拟盘。

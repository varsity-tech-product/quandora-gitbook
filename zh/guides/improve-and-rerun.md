# 改进并重新运行因子

失败的因子不等于没有价值。因子卡会告诉你哪些证据不足，并为下一次实验提供起点。

完整的界面操作教程正在准备中，后续将包括：

* 查看因子的已有版本与回测历史；
* 选择一个有证据支持的改动，并为研究方向命名；
* 把改动保存为新的检查点，同时保留原始因子；
* 只改变测试配置时，对同一个版本重新运行；
* 比较成功条件、等级、图表和风险；
* 把运行中发现的有效参数保存到新版本，并保留已经完成的运行；
* 在连续修改开始接近过拟合时停止。

在完整教程发布前，可以先让 Agent 解释失败条件，并且每次只提出一个小改动。保留每一份旧因子卡，作为完整研究记录的一部分。

## 不要混淆这些选择

| 你的目的 | 应该发生什么 |
| --- | --- |
| 为同一个因子探索不同想法 | 建立一个命名的研究方向和新检查点 |
| 修改因子定义 | 保存新的不可变版本 |
| 再次测试完全相同的定义 | 为同一个版本创建新的回测运行 |
| 保留某次运行发现的有效参数 | 把参数保存到新版本，不修改已完成运行 |

如果其他更新先一步修改了同一个研究方向，应先读取最新检查点，再决定原来的改动是否仍然适用。Quandora 不应该静默覆盖任何一方的结果。

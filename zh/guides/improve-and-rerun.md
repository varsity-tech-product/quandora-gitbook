# 改进并重新运行因子

根据一次准确运行的诊断，测试一项受控改动。保留原始证据，才能判断改动是否有效。

## 网页操作

在 **Research → Factors** 打开原结果，确认其运行、任务、预测周期和证据范围。新实验完成后，打开新结果，比较口径一致的指标。因子源码修订通过 Agent 流程完成。

## 向 Agent 提问

先请求方案：

```text
使用 Quandora Factor Analysis 为这份结果提出一项改动，说明动机证据、预期影响，以及什么结果会否定该假设。
```

准备好后授权选定实验：

```text
使用 Quandora Factor Mining 实施并回测刚才的平滑实验，保留原结果。验证完整修订源码，再用一致口径比较新运行与原运行。
```

明确的“实施并回测”请求覆盖两个步骤，Agent 无需仅因从分析切换到挖掘而重复确认。如果你要求提交前先审阅改动，Agent 应停在该审阅步骤。

## 比较口径一致的证据

先检查任务、预测周期、数据和证据范围、Health 依据，再比较成功/失败原因、覆盖率、Rank IC、自相关、Sharpe、回撤、换手和成本。不同测试窗口或适用范围可能解释差异，却不一定验证了新机制。

可选实验包括平滑噪声分数、修复缺失输出、调整归一化，或移除一个较弱输入。避免一次修改多个机制，也不要只挑选反复尝试中的最佳结果。

## 完成标准

新运行已明确定位，原结果仍可查阅，比较说明预期效果是否出现，以及带来了什么取舍。失败或证据不足的实验应如实报告。决定测试因子组合后，再进入[策略构建](strategy-tutorial.md)。

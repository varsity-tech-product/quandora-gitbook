# 分析模拟盘与实盘

解释账户已观察到的前向业绩与执行情况。选择已有模拟运行，或有权检查的自有实盘账户。实盘访问与研究访问分开，详见[实盘访问边界](../understanding-quandora/deployment-and-live-trading.md)。

## 网页操作

1. 打开 **Trading**，选择 **Paper** 或 **Live**，再选择账户和目标运行。核对来源组合及生命周期状态。
2. 阅读账户业绩和估值时间。展开净账户详情，按可用数据区分净值、余额、已实现与未实现盈亏、手续费和已结算资金费。
3. 将当前持仓与仓位表核对。模拟盘使用 **Closed positions** 和 **Filled Record**；实盘使用 **Position history** 和 **Fills** 检查对应证据。
4. 按所选窗口查看收益图，解释风险统计前先检查覆盖范围。待就绪或不完整证据应作为限制报告。

## 向 Agent 提问

```text
使用 Quandora Portfolio Trading Analysis 检查这个账户及准确运行。报告来源组合、观察区间、新鲜度、净业绩、敞口，以及账本支持的执行问题。解释与回测不同的可能原因和缺失证据。保持只读，不修改账户或研究。
```

也可以直接询问具体问题，例如资金费是否解释了已实现盈亏与账户收益之间的差异。Agent 应使用权威净账本，不应把成员快照简单相加。

## 正确解释账本

| 证据 | 解释 |
| --- | --- |
| 净值与账户业绩 | 使用记录中的资金和外部流入口径，不重复扣除已包含费用 |
| 目标或信号 | 预期敞口，不代表已执行 |
| 订单 | 已提交指令，不一定成交 |
| 成交 | 依据账户模式，表示已观察到的模拟或真实执行 |
| 未平仓或部分平仓仓位 | 当前敞口，不属于已完成持仓周期 |
| 已完成持仓周期 | 该账户记录下的已关闭生命周期证据 |

实盘订单和成交读取可能只覆盖有限近期记录，不等于完整历史导出，不能单凭它们推断全部历史手续费、换手或交易分布。滑点或延迟判断需要同步的参照与执行证据，仅有一方不够。

## 谨慎比较研究结果

数值比较需要匹配定义、日期、资金/敞口口径与成本。缺少可比对照时，应带条件地讨论观察风险与预期机制，不要编造同日期的历史重放。

区分**观察证据**、**推断**、**替代解释**和**下一项调查**。短期连续亏损可能来自噪声、运行故障、成本影响或市场状态变化，解释必须得到现有证据支持。

## 完成标准

报告明确账户与运行，说明新鲜度和覆盖范围，给出有证据支持的业绩/风险观察，并提出最小有用后续检查。缺失证据保持缺失。分析不会暂停、停止、平仓、调整权重或启动替代运行。

已授权的模拟操作继续由本工作流处理；研究修订按对象转到[组合构建](portfolio-building.md)、策略构建或因子挖掘。实盘设置和执行操作保留在网页。持续监控请求需要另有支持的调度设置；当前分析不承诺未来提醒。
